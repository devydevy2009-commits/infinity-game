# INFINITE

**INFINITE** is a minimalist arcade space shooter built for the browser, with geometric neon visuals, escalating enemy behavior, formations, evolving weapons, power-ups, and an endless survival loop.

## Release status

Phase 1 is the stable arcade foundation. Phase 2 is planned around handcrafted patterns, events, and bosses, with the goal of evolving INFINITE toward a roguelike-style endless experience.
